Project 1 Foundation Phase: Mastering Control Flow and Logic by building a rule-based chatbot.

📌 Overview
A simple rule-based AI chatbot with a beautiful Streamlit web interface. The bot uses if-else logic to respond to user greetings, answer basic AI questions, provide the time/date, and handle exit commands.

✨ Key Features
Web UI: Interactive chat interface built with Streamlit.
Greeting & Exit Handling: Responds to "hi", "hello", "hyee" and handles "bye", "exit", "quit".
If-Else Logic: Pure programmatic decision-making (no deep learning).
Continuous Loop: The Streamlit app runs in a continuous loop, maintaining chat history.
Extra Features: Tells time/date, answers basic AI questions, detects moods.

🛠️ Tech Stack
Language: Python 3.x
Framework: Streamlit
Concepts: Control Flow, If-Else Logic, Session State

🚀 How to Run
Clone the repository:
git clone https://github.com/kanwalwasim05/Kanwal-Wasim-DecodeLabs-Project1-Chatbot.git

Navigate to the folder:
cd DecodeLabs-Project1-Chatbot

Install dependencies:
pip install -r requirements.txt
Run the Streamlit app:
streamlit run app.py
